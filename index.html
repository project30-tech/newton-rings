Formulas used

Path difference (reflected) = 2·μ·t + λ/2, with t = d + r²/(2R)
Dark ring (reflected):  r_n² = R·(n·λ/μ − 2d)
Diameter:               D_n² = 4·n·λ·R/μ  (when d = 0)
Slope of D² vs n:       s = 4·λ·R/μ
Radius of curvature:    R = s·μ / (4·λ)
p-method:               R = (D²_(n+p) − D²_n)·μ / (4·p·λ)
Liquid index (same ring n):  μ = D²_air / D²_liquid
Liquid index (p-method):     μ = (D²_(n+p) − D²_n)_air / (D²_(n+p) − D²_n)_liquid
Transmitted light gives the complementary pattern (bright centre).
